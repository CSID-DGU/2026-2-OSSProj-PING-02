# 백엔드 배포 체크리스트

## 1. 컨테이너로 실행 (로컬 확인 완료)
```
cd Src/Back
cp .env.example .env   # 값 채우기 (아래 2번 참고)
docker compose --profile app up -d --build
```
- `postgres`는 기본으로 뜨고, `backend`는 `--profile app`을 붙일 때만 뜬다. 개발 때는 기존처럼 `docker compose up -d`로 DB만 띄우고 `npm run start:dev`를 쓴다.
- 컨테이너 안에서는 `DB_HOST=postgres`, `DB_SYNCHRONIZE=false`, `DB_MIGRATIONS_RUN=true`로 덮어쓴다. 서버가 시작할 때 마이그레이션이 자동 적용된다.
- 이미지는 멀티스테이지(Node 22 alpine)이고 비루트(`node`) 사용자로 실행된다.

## 2. 운영 환경변수
| 변수 | 운영 값 |
|---|---|
| `NODE_ENV` | `production` (Swagger 비노출) |
| `JWT_SECRET` | 32자 이상 랜덤 값. 예: `openssl rand -base64 48` |
| `DB_SYNCHRONIZE` | `false` |
| `DB_MIGRATIONS_RUN` | `true` |
| `DB_PASSWORD` | 기본값(`malssiat`) 사용 금지. compose의 `POSTGRES_PASSWORD`도 함께 변경 |
| `MAIL_*` | 실제 SMTP 정보. Gmail 앱 비밀번호는 하루 약 500통 제한이 있어 시연용으로만 적합 |
| `MODEL_CDN_BASE_URL` | 실제 모델 파일 주소 (현재 URL 서명 없음) |

## 3. 배포 전 확인
- [ ] `.env`가 저장소에 올라가지 않았는지 (`.gitignore`, `.dockerignore` 적용됨)
- [ ] 5432 포트를 외부에 열지 않았는지 (compose 기본은 호스트에 공개되므로 운영에서는 `ports` 제거)
- [ ] HTTPS 적용. Android는 기본으로 http 통신을 막는다.
- [ ] DB 볼륨(`malssiat-pg`) 백업 방식 결정
- [ ] 모델 다운로드 URL 서명/저장소 방식 결정
