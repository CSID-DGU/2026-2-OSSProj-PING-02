경로: `assets/icons/feature/reconnect/`

- `birthday-celebration-3d-v1.png`: 생일 축하

## UI SVG 아이콘

경로: `assets/icons/ui/`

| 파일 | 용도 |
|---|---|
| `arrow-back.svg` | 상단 앱 바 뒤로 가기 |
| `chevron-down.svg` | 선택창 또는 드롭다운 열기 |
| `checkbox-check.svg` | 선택된 체크박스 내부 체크 표시 |
| `success-circle.svg` | 완료 결과 안내 |

아이콘만 누르는 영역은 시각 크기와 별개로 최소 `44×44dp`, Android 기준 권장 `48×48dp`의 터치 영역을 제공합니다. 의미가 있는 아이콘에는 접근성 라벨을 연결합니다.
