# 🔔 알림 수집 테스트 가이드

> 카카오톡, 인스타그램, 문자 알림이 **실제로 어떤 형식으로 오는지** 확인하기 위한 테스트입니다.
> 안드로이드 폰에 테스트용 APK를 깔고, 메시지를 받아 본 뒤, 기록된 원본(JSON)을 보내 주시면 됩니다.

- **필요한 것:** 안드로이드 폰 1대, 테스트용 APK 파일

<br>

## ⚠️ 먼저 읽어 주세요 (개인정보)

- 받은 JSON은 **레포에 올리지 않습니다.**
- 테스트가 끝나면 앱에서 **원본 삭제** → **전체 삭제**를 누르고 앱을 지워 주세요.

<br>

## 1. APK 설치

1. 전달받은 `malssiat-notification-test.apk`를 폰으로 옮깁니다 (카톡 나에게 보내기, 구글 드라이브 등).
2. 파일을 눌러 설치합니다.
   - **"출처를 알 수 없는 앱"** 경고가 뜨면 → **설정** → 지금 파일을 연 앱(내 파일, 카카오톡, Chrome 등)에 **"이 출처 허용"** 을 켜고 돌아옵니다.
   - **Play 프로텍트** 경고가 뜨면 → **세부정보 더보기** → **무시하고 설치** (개발용 서명이라 뜨는 경고입니다).
3. **말씨앗** 앱을 엽니다. "알림 수집 테스트" 화면이 바로 뜹니다.

<br>

## 2. 앱 설정

### ① 알림 접근 허용
1. **알림 접근 허용하러 가기** 버튼을 누릅니다.
2. 말씨앗을 찾아 켜고, 확인 팝업에서 **허용**을 누릅니다.
3. 뒤로 돌아와서 **✓ 허용됨**이 보이면 완료입니다.

> **스위치가 회색으로 막혀서 안 켜지면 (Android 13 이상):** 파일로 설치한 앱이라 생기는 보안 제한입니다.
> 설정 → 애플리케이션 → **말씨앗** → 오른쪽 위 **⋮** → **제한된 설정 허용**을 누른 뒤 다시 시도하세요.

### ② 알림을 저장할 앱 고르기
**전체 앱 보기**를 눌러 테스트할 앱을 체크합니다.

| 앱 | 패키지명 |
|---|---|
| 카카오톡 | `com.kakao.talk` |
| 인스타그램 | `com.instagram.android` |
| 삼성 메시지 (갤럭시) | `com.samsung.android.messaging` |
| Google 메시지 (갤럭시 외) | `com.google.android.apps.messaging` |

### ③ 원본 수집 켜기
**3. 원본 수집** 아래의 **알림 원본 기록하기**를 체크합니다.

<br>

## 3. 메시지 받기

> 💡 **알림이 와야 기록됩니다.** 해당 채팅방을 보고 있으면 알림이 안 오니, 폰 화면을 끄거나 홈 화면에 둔 상태에서 받아 주세요.
> 앱 자체의 알림 설정(카톡 설정 → 알림 등)이 꺼져 있어도 기록되지 않습니다.

아래 상황을 **하나씩** 받아 봐 주세요. 할 수 있는 것만 하셔도 됩니다. 각 상황마다 무엇을 보냈는지 메모해 두면 원본과 맞춰 보기 쉽습니다.

### 카카오톡
- [ ] 1:1 대화: 짧은 텍스트 1개
- [ ] 1:1 대화: 메시지 3개 연속
- [ ] 1:1 대화: 긴 메시지 (5줄 이상)
- [ ] 1:1 대화: 사진, 이모티콘
- [ ] 단톡방 (3명 이상): 두 사람이 번갈아 메시지
- [ ] 단톡방: 나를 @멘션한 메시지
- [ ] 오픈채팅방 메시지 (가능하면)
- [ ] 카톡 설정 → 알림 → **메시지 미리보기 끄고** 메시지 1개 (테스트 후 다시 켜기)

### 인스타그램
- [ ] 1:1 DM: 텍스트
- [ ] 1:1 DM: 사진 또는 게시물 공유
- [ ] 그룹 DM
- [ ] DM이 아닌 알림: 좋아요, 댓글, 팔로우 중 하나 (DM과 구분하는 기준을 찾기 위함)

### 문자
- [ ] 일반 문자 (짧게)
- [ ] 긴 문자 (LMS)
- [ ] 단체 문자 (3명 이상)
- [ ] 인증번호나 광고 문자 (오면)

<br>

## 4. 결과 보내기

1. 테스트 화면에서 **3. 원본 수집** 목록에 카드가 쌓였는지 확인합니다.
   - 카드 아래 문구는 앱이 그 알림을 어떻게 처리했는지 보여 줍니다.
     - **새로 저장 N건**: DB에 새로 들어간 메시지 수
     - **이미 있음 N건**: 앞선 알림에서 이미 저장해서 건너뛴 메시지 수 (메신저는 새 알림에 이전 메시지를 다시 담아 보냄)
     - **저장 안 함**: 본문이 없어서 저장하지 않은 알림
   - "새 메시지 3개" 같은 묶음 요약 알림은 원본 목록에도 나오지 않습니다.
   - 카드를 누르면 원본 전체가 펼쳐집니다.
2. **상황별로 1개씩 보내 주세요 (추천).** 위 체크리스트의 상황마다 대표 카드 하나면 충분합니다.
   - 카드를 눌러 펼친 뒤 **이 원본 복사** → 슬랙이나 카톡에 붙여넣기
   - 붙여넣을 때 "카톡 단톡방 텍스트"처럼 어떤 상황인지 한 줄 적어 주세요.
   - 펼친 내용을 길게 누르면 일부만 선택해서 복사할 수도 있습니다.
3. 한꺼번에 보내고 싶다면 목록 위의 **JSON 복사** 또는 **공유**를 누릅니다. 최근 50개가 한 번에 나갑니다. (내용이 길면 메모 앱이나 드라이브에 저장해서 파일로 보내 주세요)

<br>

## 🛠 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 카드가 하나도 안 쌓임 | ① 알림 접근이 ✓ 허용됨인지 ② 해당 앱을 체크했는지 ③ **알림 원본 기록하기**를 체크했는지 ④ 폰 알림창에 실제로 알림이 떴는지 |
| 알림 접근 스위치가 안 켜짐 | 위의 **제한된 설정 허용** 참고 |
| 화면이 갱신되지 않음 | **4. 저장된 알림**의 **새로고침**을 누르거나, 홈으로 나갔다가 다시 들어오기 |
| 한동안 잘 되다가 안 쌓임 | 설정 → 애플리케이션 → 말씨앗 → 배터리 → **제한 없음**으로 바꾼 뒤, 알림 접근을 껐다가 다시 켜기 |

<br>

## 개발자용: 테스트 APK 만들기

`Src/Front/`에서 아래처럼 빌드합니다. 테스트 화면에서 바로 시작하도록 `src/routes/router.tsx`의 `initialRouteName`을 잠시 `"NotificationDebug"`로 바꾸고 빌드한 뒤, **커밋 전에 `"Splash"`로 되돌립니다.**

```bash
cd android && ./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a
```

결과물은 `android/app/build/outputs/apk/release/app-release.apk`입니다. JS가 APK 안에 들어 있어서 Metro 없이 동작합니다.
